## Candidate Boundaries

### candidate_revision

Trace attacker-influenced URL or endpoint values from API, plugin, configuration, webhook, callback, or bridge inputs into outbound HTTP request construction and dispatch. Review whether the HTTP client receives the same host and scheme that the security policy parsed and validated. Require destination controls that reject disallowed schemes and private, loopback, link-local, multicast, unique-local, and cloud-metadata addresses after resolution; apply equivalent checks to redirects and prevent DNS or parser inconsistencies from bypassing the decision. Report only when an untrusted or insufficiently constrained destination can reach the outbound request path.
