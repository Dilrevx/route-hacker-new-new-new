## Candidate Boundaries

### candidate_revision

Trace attacker-controlled redirect targets, callback URLs, return URLs, Referer-derived destinations, OAuth/OIDC redirect_uri values, and browser navigation targets into redirect responses, Location headers, response.sendRedirect, window.location assignments, or protocol authorization redirects. Report a path when the final decoded and normalized destination can reach an external or unsafe-scheme target without an exact policy check. Require the guard to validate the final parsed URL on the same source-to-sink path: permit only relative paths resolved against the expected origin, exact registered callback URIs, or explicitly allowlisted scheme/origin/path combinations. Reject prefix-only matching, ambiguous normalization, protocol-relative targets, and non-browser-safe schemes unless explicitly registered.
