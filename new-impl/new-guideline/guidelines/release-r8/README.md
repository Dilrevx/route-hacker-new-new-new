# Released R8 Guidelines

This directory contains the release-ready cluster-mechanism guideline catalog
used by the paper evaluation.

- `guideline_overrides.jsonl`: 189 case-addressable guideline assignments.
- `index.json`: 177 released mechanism-level guidelines.
- `mechanism_candidates.jsonl`: mechanism attribution records from which the
  released catalog was selected.
- `summary.json`: release counts and source fingerprint.

Pending mechanisms are not included in the released guideline index or
guideline overrides. The files contain public vulnerability identifiers and
mechanism-level security obligations, but no local execution paths or author
metadata.
