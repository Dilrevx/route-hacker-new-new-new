The Maven settings file manually configures an HTTP proxy and an Aliyun mirror to bypass network restrictions. The build excludes several modules (`assemblies`, `itests`, `examples`, `archetypes`, `manual`, `docker`) because they either require additional dependencies or fail to compile for this specific revision. Java 8 (Temurin) is enforced, as Karaf at revision 20 may not be compatible with newer JDKs.
