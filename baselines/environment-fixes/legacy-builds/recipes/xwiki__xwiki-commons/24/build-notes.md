Build required explicit proxy configuration in Maven settings.xml and use of Java 8 (Temurin) and Maven 3.5.0, as this older revision of xwiki-commons depends on dependencies only resolvable with those versions. The proxy was necessary to reach artifact repositories behind a corporate firewall, and the specific tool chain avoids compatibility issues with later Java or Maven releases. Watch for that any future build of this revision must enforce Java 8 and Maven 3.5.0, and have a working HTTP proxy for dependency resolution.
