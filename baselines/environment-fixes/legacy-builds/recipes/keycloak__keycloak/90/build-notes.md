A dummy `keycloak-admin-ui` artifact (version 999-SNAPSHOT) is built and installed locally before the main build. This step is required because at revision 90 the admin-ui wrapper module depends on this artifact, but it is not upstream in the Maven repository – likely due to incomplete artifact publishing or build order issues. Watch out that the dummy version must match the dependency version expected by the wrapper; any mismatch will cause resolution failures. The Maven settings also configure a proxy and AliCloud mirror to speed up downloads behind a firewall.
